TX/RX isolation: where we are

The radar has two identical 8×12 patch arrays side by side: TX and RX, 3.3 mm element pitch, beams steered by true time delay within ±20° in azimuth and elevation, 95–99.9 GHz. The requirement is 70 dB between the whole TX panel and each RX channel. This page lists the best numbers reached so far and the CST pictures and graphs they come from. Every step is in the simulation log.

Last updated 25 Oct 2026. Simulated numbers and estimates are marked separately.

Full-size simulations (no radome)

Both runs are the complete TX 8×12 + RX 8×12 system in CST (time-domain solver). One RX channel was excited, the corner element next to the gap, and the TX beam was then formed for every steering direction from the coupling to all 96 TX elements.

Why steering away from the RX array is worse. At 99.9 GHz the wavelength (3.00 mm) is shorter than the 3.3 mm element pitch, so the TX array has grating lobes. For the worst directions one grating lobe lies right along the panel surface, pointing diagonally towards the RX corner. Energy then travels along the gap, and the TX elements along the gap add up almost in phase. This is also why the full system is 10–15 dB worse than the small 4×4 test models. An amplitude taper would not remove a grating lobe; a smaller pitch (below 2.89 mm) would.

Best design so far: radome + metal wall up to the radome

The plate is raised from 1.4 mm to 5.87 mm, so it becomes a wall whose top touches the underside of the radome and closes the air path between the arrays. The radome is a generic placeholder (flat slab, εr 3.0, loss tangent about 0.01, 0.888 mm thick, 5 mm above the patches) until the real radome design is available.

A full-size model with the radome has about 357 million cells and needs an estimated 125–165 GB of memory, at or above the 128 GB of the largest machine available. So the radome + wall design was simulated on two smaller models: TX 4×4 + RX 4×4, and TX 2×12 + RX 2×12 (the two columns on each side of the gap over the full 12-row gap length).

How the ≈ 65 dB estimate is made. Start from the full-size 5 mm plate run (45.2 dB). Add the improvement of radome + wall over the plate measured on the 2×12 model (about 19 dB for the corner channel). Then correct for the six TX columns that the 2×12 model leaves out, using the column trend of the full-size runs, and for the boundary setting. Result: coupling B about −45 dB (−49.5 to −40.8), leakage about −36 dBm, isolation about 65 dB (61–69). The range comes mainly from the missing TX columns. This is an estimate until a full-size radome run is possible.

Numerical quality

  • Repeatability of the setup (mesh and boundary checks): about ±1 dB.
  • The corrugated plate stores energy in its grooves, so the simulation rings for a long time. Runs with the plate were stopped at 3 ns (4 ns for the first one) before the energy had fully decayed. Cutting the record by 10 % moves the worst-case values by 0.1–0.7 dB, so the true worst case may be a few tenths of a dB higher.
  • Runs with radome + wall decay normally and stop on the −60 dB energy criterion.
  • Radome runs need enough air and absorbing layers above the radome. The first radome runs (1.75 mm air, 4 layers) were about 1 dB optimistic; with 3 mm air and 8 layers the values change by 0.02–0.04 dB when the air is increased further, so that setting is used from now on. The numbers on this page include this correction.

Running now and next steps

  • running 4×4 model with the radome cut above the wall: a 5 mm metal strip through the radome, so the wall continues to the outer surface. The port data suggest that the remaining leak crosses the wall inside the radome slab; this run tests that directly. The first attempt was numerically unstable and is being repeated with a corrected model.
  • queued Memory test: how much memory a radome model needs when the solver uses fewer CPU threads, to see whether a full-size radome + wall run can fit in 128 GB.
  • Then: confirm the best radome cut on the 2×12 model, and run the full-size radome + wall model if the memory test allows it.
  • Open: the real radome design and the final plate/wall CAD; RX channels other than the corner one at full size.

Definitions

  • Requirement. 29 dBm total TX power (96 channels, 9.2 dBm each). 70 dB isolation means at most −41 dBm leakage into any single RX channel, for any TX beam direction within ±20° and any frequency in 95–99.9 GHz. (RX input IP3 is −18 dBm; FMCW, so TX and RX are on at the same time.)
  • Coupling B. Power into one RX channel with the whole TX beam on, relative to the power of one TX channel. Leakage = 9.2 dBm + B; isolation = 29 dBm − leakage = 19.8 dB − B. The requirement is B ≤ −50.2 dB.
  • Reduced models. 4×4 + 4×4 and 2×12 + 2×12 models use the same element, gap and plate and are shown on the B scale. They have fewer TX elements than the real panel, so their B is not the full-panel value: with the plate the full system was 10–15 dB worse than the 4×4 model.
  • Worst case. Worst over all TX steering directions within ±20° (1° grid) and over 95–99.9 GHz. TX beams use ideal true-time-delay weights with uniform amplitude.

CST Studio Suite 2026, time-domain solver. Isolation results from single-RX-port runs; TX beams formed from the simulated coupling to every TX element (reciprocity).
